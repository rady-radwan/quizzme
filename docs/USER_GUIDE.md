# Quiz me — user guide

## 1. Organise your material

**Banks** tab → **New subject** (e.g. *English*). Open the subject's menu (⋮) to add categories (*Grammar*), sub-categories (*Tenses*) and **question banks**. Any category can contain both sub-categories and banks, as deep as you like. Use ⋮ to edit the name, description, icon and colour, move, archive (hide from quizzes without deleting) or delete (you type DELETE to confirm).

Opening a bank shows its statistics immediately: total questions, never attempted, attempted, mastered, needing review, overall accuracy and questions due today.

## 2. Add questions

- **From Excel** — bank → *Import from Excel* (or Settings → Import questions). Download a template from the same screen, fill it in, choose the file, check the preview and press *Import*. See [EXCEL_FORMAT.md](EXCEL_FORMAT.md).
  - Questions already in the bank: choose *Skip*, *Update* (keeps learning history) or *Add anyway*.
  - Images/audio: put them in a .zip with the workbook, or use *Add media files* in the preview.
  - After the import the questions live in the app; the Excel file can be deleted.
- **By hand** — bank → **+**. Pick the type, write the question and answers, mark the correct one(s), and optionally add hint, feedback, explanation, difficulty, tags, image, audio, source and notes.

## 3. Take a quiz

**Quiz** tab (or *Start quiz* on a bank/category):

1. *What to study* — subjects, categories or banks. Selecting a category includes everything inside it; then tap the ✓ next to a sub-category to exclude it.
2. *Mode* — Learn New Questions, Review, Mistakes, Spaced Repetition, Random, Mastery Test, Bookmarked, Quick Review.
3. *Style* — Practice (relaxed, hints), Exam (no hints, answers after submitting, optional countdown) or Cards (flashcards).
4. *Number of questions* — 5/10/25/50/100 or a custom number.
5. *Show answers* — after each question or at the end.
6. *Advanced settings* — hints, shuffling, timer, include attempted questions, confidence ratings, adaptive difficulty, difficulty and mastery filters, automatic or manual distribution across banks.

The bottom bar shows how many questions are available. If you ask for more, the app offers to start with the available number — it never repeats questions to fill a quiz.

During a quiz: tap an answer (nothing is submitted by accident), **Submit answer**, read the feedback, rate how well you knew it, **Next**. Use ◀ to go back, the grid icon to jump to any question or the next unanswered one, the bookmark, the hint 💡 and 🔊 read-aloud. Leaving keeps the quiz: *Continue last quiz* appears on Home.

## 4. Revise

- **Spaced repetition** — every answer schedules the next review. *Review now* on Home (or Progress → Overview) runs today's due questions; overdue ones come first.
- **Mistakes Notebook** — Home → *Review Mistakes*: your answer, the correct answer and the explanation. Filter by subject, repeated mistakes or bookmarks; add notes; *Mark as understood* (history is kept); *Quiz from mistakes*.
- **Flashcards** — tap to reveal, rate *Forgot / Hard / Medium / Easy*; swipe for the next card.
- **Quick Review** — a short session of due and most-difficult questions.
- When you have finished every new question in a bank you can review, practise mistakes, start spaced repetition or reset new-question progress (statistics are kept).

## 5. Track progress

**Progress** tab: overview statistics, revision dashboard and upcoming reviews, mastery distribution, study calendar; activity charts by day, week or month; weakest topics with *Practice my weak topics*; per-subject mastery; daily goals with streaks; achievements; quiz history (tap any quiz to reopen its full results).

Each question page explains its mastery status in plain words ("Recalled 4 times in a row; next review in 30 days").

## 6. Export, backup and restore

- **Export a bank** — bank → *Export to Excel* (or Settings → Data management). Re-importable.
- **Backup** — Settings → *Backup & restore* → *Create backup*. One .zip with everything. Save it to cloud storage or a computer regularly.
- **Restore** — choose a backup, check the preview, type RESTORE. A safety copy of the current data is saved first. Restoring replaces all current data.

## 7. Settings

Theme (Light, Dark, AMOLED, Minimal White, Sepia, custom accent), font, text size, line spacing, high contrast, reduced motion, layout direction; quiz defaults; daily goal, confidence ratings, adaptive difficulty, spaced-repetition intervals; reminders (time, days); achievements; read-aloud speed; data management (import, export, backup, database info, reset new-question history, clear learning progress).

## 8. Using Quiz me on Windows

The PC version works the same way as the phone app, with keyboard shortcuts:

- **Ctrl+1 … Ctrl+5** — Home, Quiz, Banks, Progress, Settings.
- In a quiz: **1–9** or **A–J** choose an option, **Enter** checks the answer or goes to the next question, **← / →** move between questions, **H** shows the hint, **Ctrl+B** bookmarks, **Ctrl+G** opens the question grid, **Ctrl+R** reads aloud, **Ctrl+Enter** submits, **Esc** leaves (your answers are saved). **F1** lists the shortcuts.
- In flashcards: **Space** or **Enter** reveals the answer / goes to the next card, **1–4** rate it, **← / →** move between cards.

While you type in an answer box, the letter and arrow keys type normally; **Enter** still checks the answer and **Esc** leaves the box.
To move your library between phone and PC, create a backup on one device and restore it on the other (Settings → Backup & restore).
